# Ad images

Assets for Google Ads (and any paid social). All 1200px, ready to upload.
Google Ads image slots want 1:1 (square) and 1.91:1 (landscape).

## Report images (real quickler output, anonymised - use these first)
- `report-pass-1x1.png` / `report-pass-1.91x1.png` - a 100%, 53/53, 0-issues
  Fire Risk Assessment (all green). Best "here is what you get" visual.
- `report-issues-1x1.png` / `report-issues-1.91x1.png` - a 59%, 15-issue
  report (red flags). Shows the tool actually catches problems.
- `report-partial-1x1.png` / `report-partial-1.91x1.png` - an 89%, 5-issue
  report. The address and weather block were cropped out for privacy.

All three use test/placeholder IDs (Foxtrot Romeo Alpha, FRA-2026-114) - no
real client name, address, or data. Do NOT put real client reports (RI
Cruden, G Simpson, Graeme PDFs in Downloads) into public ads, even
anonymised.
