Troubleshooting

Engineer isn't receiving the intro message

  • Check the number. Country code matters — UK mobiles are 07 or +447.
  • WhatsApp must be installed on the same number as the mobile account.
  • If the engineer has blocked unknown numbers, ask them to unblock Quickler's sender.
  • Still nothing? Remove the engineer and re-add.

Engineer stopped halfway through

Partial answers are saved. They can reply to the same WhatsApp chat at any time and pick up where they left off.

PDF looks wrong

  • Missing question: did you add it after the run started? Runs use the workflow version they were sent with.
  • Photo sideways: WhatsApp sometimes strips rotation data. Ask the engineer to retake the photo held upright.
  • Missing answer: the engineer may have skipped the question or replied with something the system couldn't parse. Check the run details on the dashboard.

Error page with a reference code

We're notified automatically. If it's blocking you, email hello@quickler.co with the reference code.

Hit the workflow or engineer limit

Click the upgrade prompt on the dashboard. You pay the pro-rata difference for the rest of the cycle.

Can't sign in

  • Magic links expire after 15 minutes. Request a new one.
  • Each link works once.
  • If you've requested several links in a short time, wait a few minutes before trying again.

Something else

Email hello@quickler.co.

Still stuck? Email hello@quickler.co — we reply within one business day.
