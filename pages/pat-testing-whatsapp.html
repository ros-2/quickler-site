PAT testing batches over WhatsApp.

For PAT testers and the firms that employ them. How a PAT batch runs as a Quickler workflow — appliance ID, location, test result, photo of the label, all captured in the WhatsApp chat already on the tester's phone.

Why PAT testing is a good fit for WhatsApp capture

PAT testing is volume work: a tester can get through a high volume of items in a day. Each item needs the same handful of fields recorded — appliance ID, location, class, test result (pass/fail), date, tester. Doing this on a clipboard is slow; doing it on a dedicated PAT testing app means the tester has to switch between the tester instrument and the app for every item.

WhatsApp keeps the tester's attention on the instrument. The tester ID-stickers an item, performs the test, takes a photo of the new label with the appliance ID visible, and sends the result as a single chat message: A0124 pass. The next item is ready to test.

The workflow

  1. Site and customer go into the dashboard. The batch starts.
  2. For each item the tester sends a short message in the format [appliance ID] [pass/fail] [class I/II] [location] [photo].
  3. Quickler parses the message into the right fields. The PAT register is built up live.
  4. Any failed item triggers an immediate flag — the customer can be told before the tester leaves the site.
  5. On completion the batch produces the PAT register PDF (the full list) and per-item certificate PDFs for failed items the customer needs to remove from use.

What the register PDF contains

Site address, customer, tester name and qualification, date range, the full numbered list of items tested, the pass/fail outcome per item, the class per item, the location per item, and any notes. The format matches IET Code of Practice expectations for record-keeping.

Frequently asked questions

Does this replace the PAT tester instrument?

No. The tester still uses their PAT instrument. Quickler replaces the clipboard or the dedicated PAT app the tester would use to record results.

How are appliance IDs handled?

Each item gets a barcode or RFID sticker as today. The tester types the appliance ID (or uses WhatsApp's camera to scan a QR-coded sticker, if used) as part of the result message.

What about retest dates?

Each item's retest date is calculated from the test date and the class. The dashboard surfaces upcoming retests so the customer can schedule the next batch without manual diary work.

Can the customer see the register live?

Yes. The customer can be given read-only dashboard access. As the tester moves through the batch, the register updates row by row in real time.

Does it meet IET Code of Practice?

The output PDF carries every field the IET Code of Practice requires for in-service inspection records. The tester's qualification is recorded against the batch.
